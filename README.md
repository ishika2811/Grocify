## 🔗 API Endpoints

### Products

```http
GET /api/products
```

Fetch all products.

```http
GET /api/products/:id
```

Fetch product details.

### Cart

```http
POST /api/cart
```

Add product to cart.

### Orders

```http
POST /api/orders
```

Place a new order.

### Authentication

```http
POST /api/users/login
```

User Login.

```http
POST /api/users/register
```

User Registration.
